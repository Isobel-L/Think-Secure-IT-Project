# Assistant artwork

Generated with the built-in imagegen tool, using the existing ThinkSecure robot as the identity reference and user-supplied full-body artwork as proportion reference. Guide and think variants use the generated wave image as their identity reference.

Project assets: `robotimage/assistant-wave.png`, `robotimage/assistant-guide.png`, `robotimage/assistant-think.png`.

All assets retain transparent backgrounds, the shield with one star, navy/white/violet styling and pupil-free luminous eyes. These are calm full-body gestures with no text or decorative motion trails. Existing password-strength and avatar assets are unchanged.
